# SSSPF-EVS

Here, we predict drug combinations involving Dipeptidyl peptidase-4 inhibitors for treatment of Polycystic Ovarian Syndrome 

For computational convenience,drugs have been named as drug_1, drug_2, etc and proteins have been named as prot_1, prot_2, etc


Directions for execution:

Download all files in 1 folder

1. First execute GCN_dp_all.py

2. Execute mydisease_consolidated_validation_prediction_results.py.
